# 我今年3岁 · game01

面向约3岁儿童的中文互动网页游戏。和小汽车、小兔、小熊及动物朋友一起旅行，通过一次点击或宽容拖动帮助朋友，体验温和的动画与声音反馈。每关只有一个主要动作，成功后自动进入下一关，不设分数、倒计时或失败惩罚。

[在线体验](https://35.220.184.100/) · [GitHub仓库](https://github.com/hk61023/3yers)

点击目标和拖动物支持键盘操作；拖动提供宽容吸附，可按Enter或空格完成。成功后保护重复触发，静音或降低动态效果时仍能完成旅程。完成页可重玩或返回原目录页；顶部品牌和刷新回到第一页。手机与平板支持纵向滚动。

## 声音与素材

家长设置分别控制背景音乐、互动音效和中文语音，选择保存在当前浏览器。声音在用户首次操作后解锁，音频不可用时不阻塞游戏。

- 12个主题各有专属BGM，共15首背景音乐。第一页和第二页目录循环两首菜单曲，第三页目录播放《Starry Sky Spaceship Journey》。
- 中文提示使用随项目发布的本地MP3；语音期间降低BGM音量，页面隐藏时暂停背景音乐。
- 音乐派对使用与画面对应的乐器声音，最后三关为古筝、二胡、八音盒。有声模式完整演奏6.4秒后推进，演奏期间暂停BGM；静音和播放失败保留视觉反馈与推进兜底。
- 游戏插画使用本地WebP，每张不超过300,000字节。角色、道具与背景分层，盖被等关卡使用匹配的完整完成画面。
- 发布MP3超过500,000字节时压缩；超过两分钟的音频不超过1,000,000字节。保留完整时长与立体声，原始音乐不改写。15首BGM压缩后总体积约13.1 MB。

曲目映射和音频规则见[背景音乐说明](public/audio/bgm/README.md)与[语音说明](public/audio/voice/README.md)。

## 本地运行

前端使用React、TypeScript和Vite。需要Node.js 20.19+（20.x）或22.12及以上版本；以下为Windows命令，其他系统使用`npm`代替`npm.cmd`。

```powershell
npm.cmd install
npm.cmd run dev -- --host 127.0.0.1 --port 5173
```

打开 http://127.0.0.1:5173/ 。检查与生产构建：

```powershell
npm.cmd run lint
npm.cmd run build
git diff --check
```

构建产物位于`dist/`，可由Nginx等静态服务器提供。独立访问统计服务位于`backend/`，前端上报失败不影响游戏；本地游玩无需安装统计服务。

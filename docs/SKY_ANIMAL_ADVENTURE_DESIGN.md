# 天空旅行：小兔与小熊的十站冒险

日期：2026-10-04。状态：**十关玩法、分层素材与语音已实现**。

本文记录十关设计基准及已完成实现。专用组件为 `src/themes/sky/SkyAdventureScene.tsx`，本地素材位于 `public/images/themes/sky/adventure/`。本次发布按用户授权进行提交、推送及上线，发布结果以交付说明为准。

## 1. 故事与角色

小兔、小熊从家附近的草地乘气球出发，小鸟带路，到云上车站换乘云火车，游览彩虹桥和邮递站。小雨过后回到停靠的气球，傍晚由萤火虫带路回家，最后在小屋一起入睡。

- 小兔：暖白毛、粉色耳内、珊瑚色围巾，圆润脸型；耳朵和挥手是主要情绪动作。
- 小熊：浅棕毛、奶油色背心，圆耳朵；通过目光、扶帽、吹气和点头表达情绪。
- 小鸟：浅蓝身体、奶油色腹部、小黄喙；第2、4、7关是同一只小鸟。
- 鸽子：灰白身体、淡紫颈部、小型珊瑚色邮袋。萤火虫：圆润小身体、淡黄绿色发光腹部。
- 气球：奶油色与淡珊瑚色条纹球囊、浅棕编织篮、薄荷色包边；各关使用同一造型。云火车：蓝色车身、奶油色云顶，车头统一朝左。
- 第4–8关属于同一个云上站点，包含车站、观景桥、邮递角和树荫雨棚。每处通过同一组薄荷色栏杆、圆木招牌和云台地面建立连续性；气球停在站点码头。

角色先有需要，再由孩子帮忙，最后明确回应。伙伴不用焦急、哭泣或惊吓表情；未操作时安静期待。背景不能出现额外的帽子、信、伞、风车、萤火虫或被子，使操作对象始终唯一。

## 2. 构图与时间约定

下文位置为场景可视区域的百分比坐标，左上角为(0,0)。它们是制作锚点；触控大小优先于百分比尺寸。

- 标题位于顶部，保留y=0–20的安静区域；动物和关键动作集中在y=28–82。装饰位于边缘，不能挡脸或目标。
- 同时准备桌面横构图与手机竖构图。手机须重新安排图层，不能直接裁切横图；角色、关键交通工具、操作对象及目的地完整保留。
- 拖动关默认源位置(20,80)、目标位于中央偏右。源和目标触控区域至少104×104 CSS像素；拖动宽容范围沿用72像素，Enter/空格可直接完成。
- 每关一个主要动作。点击关只启用一个按钮；拖动关只启用一个物件、一个目的地。动物其他部位及背景均不接受操作。
- 未操作时允许轻微呼吸、耳朵摆动和目光提示，不自动执行任务。安静提示沿用现有机制。
- 操作成功立即禁用目标。正常反馈固定3.6秒：0–0.6秒操作生效，0.6–2秒动物回应，2–3.6秒旅程继续，再自动推进。
- 降低动态效果时直接展示明确完成态，停留1.2秒后推进；不依赖动画结束事件。静音时全部剧情仍能通过画面理解。
- 不出现成绩、失败、催促、倒计时或额外下一关按钮。拖偏只回弹，不改变剧情状态。

## 3. 十关制作分镜

### 01 朋友坐气球

候选ID：`sky-balloon-launch`；点击。镜头为草地起飞全景。

**初始画面：** 晨光草地占画面下部，远处是之后会回到的小屋。气球完整位于中央，篮子中心(50,67)；小兔在篮内左侧、小熊在右侧，两位伙伴已经坐好。小兔望向篮子前沿，小熊扶着篮沿。不能要求孩子先完成登篮动作。

**操作瞬间：** 点击篮子前面的大区域。篮沿轻亮，小兔举手，小熊握稳；篮子连同球囊和角色一起移动，角色不能穿出篮壁。

**成功画面：** 小兔挥手、小熊点头，气球缓缓升起，地面轻轻向下移，显露更多天空。降低动态效果使用较高的气球位置和已挥手的伙伴。

- 中文提示：点一点气球篮，出发吧。
- 无障碍标签：让小兔和小熊乘气球出发。
- 成功文案：朋友坐好啦，气球出发！
- 图层：晨光草地背景、球囊与绳、篮后壁、两位伙伴、篮前壁；小兔挥手、小熊点头姿态。篮前壁位于角色前方，所有交通工具层共用父级位移。
- 提示音效：柔和风声与短挥手回应，不使用真实热气球燃烧声。

### 02 小鸟来领路

候选ID：`sky-bird-guide`；点击。镜头为气球篮中近景，云海在远处。

**初始画面：** 篮子下沿从画面底部进入，小兔、小熊在(39,66)、(62,66)。小鸟停在篮沿(55,48)，清楚看向前方，挡路云位于(70,37)。云不表现为可点击对象。

**操作瞬间：** 点击小鸟。它先点头，再展翅离开篮沿；小兔、小熊的视线跟随。小鸟的点击区域成功后立即禁用，不能追着点击。

**成功画面：** 小鸟向左上方飞去，挡路云同步向右移开，出现通路；气球小幅向前浮动，伙伴开心挥手。

- 中文提示：点一点小鸟，请它带路吧。
- 无障碍标签：请小鸟为气球带路。
- 成功文案：小鸟带路，前面通畅啦！
- 图层：高空背景、篮子近景、两位伙伴的期待/跟随/挥手姿态、独立挡路云、小鸟停靠/展翅姿态。
- 提示音效：两声轻柔鸟鸣；云移动不播放机关声。

**操作瞬间：** 把帽子送到小熊头上；目标中心(65,40)，只显示一个柔和帽形提示。吸附后帽子贴合头顶，清除目标提示和源帽子。

**成功画面：** 小熊扶扶帽檐、微笑，小兔拍手。帽子之后继续出现在第4–9关的小熊身上，第10关放在床边固定挂位。

- 中文提示：给小熊戴上帽子吧。
- 无障碍标签：把遮阳帽戴到小熊头上。
- 成功文案：帽子戴好，小熊舒服啦！
- 图层：篮内背景、伙伴独立层、透明帽子、小熊扶帽姿态、小兔拍手姿态。帽子与头部轮廓单独适配，不用整个人物移动模拟戴帽。
- 提示音效：柔和落位声与短开心回应。

### 04 云火车接朋友

### 05 小兔过彩虹桥

### 07 给小鸟撑伞

- 中文提示：把小伞送到小鸟上方吧。
- 无障碍标签：把小伞撑在小鸟上方。
- 成功文案：小鸟有伞，不淋雨啦！
- 图层：雨棚树枝背景、伙伴、小鸟两种姿态、透明伞、独立雨层及伞下遮雨区域；无雷电与骤暗效果。
- 提示音效：轻雨声，完成时两声鸟鸣。
